# Körper — gemeinsame Grundlage für Instrumentenkörper

## Entscheide (SSOT)
`docs/audio/Spielweisen_Konzept.md` §4.1: **KB1 a** (S146) — ein Körper ist eine Liste von Moden (Frequenz,
Dämpfung, modale Masse je Einkoppelpunkt, Abstrahlgewicht je Ausgang), oberhalb einer Grenzfrequenz ein
statistischer Teil; offline zu Antworten gerechnet, per Faltung angewandt; was sich je Instrument unterscheidet,
kommt als Erweiterung auf die Basis. Vorher: die Gitarrenkorpusse Parlor und Classical (Saiten_Konzept §6, S-K8 a,
S-K10 a) als gekoppelte Schwinger.
