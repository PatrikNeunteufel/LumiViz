# Rohr — gemeinsames Rohrmodell der Klassen 7, 8, 9

> **Seit:** S182 (2026-11-09), Auflösung von InstrumentsCalculation (AU1-1 a).

Das Rohrmodell für Lippe, Rohrblatt und Luftstrahl und die Recherchen dazu (Verfahren, Moden und Waveguides, freie Aufnahmen von Blasinstrumenten). Die Klassenordner `lippe-rohr`, `rohrblatt-rohr`, `luftstrahl-rohr` verweisen hierher.
