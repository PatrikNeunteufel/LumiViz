# Composer — Blenden-Presets

Mitgelieferte Kurvenformen fuer Ein- und Ausblendungen (`.lvfade`). Eine Form
laeuft von (0, 0) nach (1, 1) und traegt keine Zeit; als Ausblendung wird sie
rueckwaerts gelesen. Eigene Presets liegen im Benutzerordner
`<AppData>/composer/fades/` und verdraengen ein mitgeliefertes gleichen Namens.

Diese Datei ist der Anker, an dem die App den Ordner findet — nicht loeschen.
Beschreibung: `projects/apps/LumiViz/docs/ui/Composer_Konzept.md` §9.
